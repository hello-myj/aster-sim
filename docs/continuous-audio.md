# 连续音效

当前 ABI 为 4.1.0，模拟器版本0.3.0，随SDK `sdk-v4.1.0` 提供。

无窗口模型推进音效相位和参数状态；浏览器用Web Audio播放循环、交叉淡化、变速与淡出。需要先启用声音。浏览器在APP启动后连接也会收到循环状态；刷新后循环从引入段重新开始，不承诺与后台模型逐采样对齐。单次音效不会因浏览器重连而重放。

SDK公开契约提交由src/sdk-compat.json.sdkCommit固定；SDK开发包最终元数据提交另见release.json.commit。配套清单通过sdk_contract_revision解释这两个提交的关系，并校验完整公开契约哈希。

固件已实现 SD 文件预读；无缝切歌和独立解码/输出线程不在本版功能范围，游戏工程需要自行接入循环音效接口。模拟器不模拟ESP32硬件，不提供audio-stream。

Windows 原先在 WASM Trap/分配失败后的原生 Canvas 线程环境回收阶段间歇访问异常。现在 Windows 使用独立进程运行 APP 与原生图形，Linux 保持工作线程；通信消息、异常报告和看门狗语义不变。回归包含重复 Trap/分配失败、正常进程退出、阻塞进程强制回收和完整测试集。

模拟器与两款固件的版本、提交和校验关系见 SDK 包内 development-kit.json。固件实机已完成两板正常音频和交互验收；浏览器重连不保证相位同步，硬件故障注入及长期压力不在此次模拟器回归范围。
